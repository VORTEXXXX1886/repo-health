# Contributing to repo-health

Thanks for considering a contribution! Bug reports, documentation improvements, and focused checks are welcome.

## Development setup

- Use Python 3.10 or newer.
- Clone the repository and install it with `python -m pip install -e .`.
- Run tests with `python -m unittest discover -s tests -v`.

## Pull requests

- Keep changes focused and explain the problem they solve.
- Add or update tests for behavior changes.
- Update the README when changing user-facing behavior.
- Do not add a runtime dependency without discussing the tradeoff in an issue first.
